# DMS Application Rules & Policies

## 1. Supported Document Formats
* **Allowed Formats**: Only PDF (`.pdf`), Word (`.doc`, `.docx`), and Excel (`.xls`, `.xlsx`).
* **Forbidden Formats**: Video files (such as `.mp4`, `.mov`, `.avi`), Audio files (`.mp3`, `.wav`), and archive files (`.zip`, `.rar`) are **strictly NOT supported** and cannot be uploaded.

## 2. File Upload Limits
* **Maximum File Size**: 50 MB per document.

## 3. Document Approval Process
* **Draft**: Created by the author.
* **Under Review**: Submitted by author, pending reviewer/admin approval.
* **Approved**: Active and effective. Can be revised.
* **Rejected**: Returned to draft with review comments.
